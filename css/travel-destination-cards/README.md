# Travel Destination Cards

A simple responsive landing page built using only HTML and CSS.

## Features

- Responsive navigation bar
- Hero section
- Destination cards
- About section
- Footer
- Mobile-friendly layout
- No JavaScript

## Technologies Used

- HTML5
- CSS3

## Folder Structure

```
travel-destination-cards/
│
├── index.html
├── README.md
├── css/
│   └── style.css
└── images/
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
