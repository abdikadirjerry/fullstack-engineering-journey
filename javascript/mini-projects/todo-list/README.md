# To-Do List

A simple and responsive To-Do List built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Prevent empty tasks
- Responsive design
- Clean user interface

## Technologies

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Practiced

- DOM selection
- DOM manipulation
- Event listeners
- Form submission
- Preventing default browser behavior
- Functions
- Variables
- Conditional statements
- Creating elements
- Adding classes
- Removing elements
- User input handling

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Goal

The goal of this project is to practice JavaScript DOM manipulation, events, user input, and basic application logic.
